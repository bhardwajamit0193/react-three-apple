<div>
  <h1>✨ React 3D Apple Showcase</h1>
  <p>An immersive, high-end web experience built with React, Three.js, GSAP, and TailwindCSS. Showcase products in dynamic 3D environments with realistic lighting, scroll-triggered animations, pinned sections, and fluid timeline transitions.</p>

  <hr>

  <h2>⚙️ Tech Stack</h2>
  <ul>
    <li><strong>React:</strong> A declarative JavaScript library providing the modular component architecture for interactive UIs, smooth GSAP integration, and state-driven features.</li>
    <li><strong>Three.js:</strong> A powerful 3D library leveraging WebGL to render interactive graphics, cameras, realistic lighting, materials, and 3D model manipulation in the browser.</li>
    <li><strong>GSAP (GreenSock Animation Platform):</strong> A robust animation engine handling scroll-driven visuals, ScrollTrigger timeline control, pinned sections, image masking effects, and smooth multi-section transitions.</li>
    <li><strong>Tailwind CSS:</strong> A utility-first CSS framework used to rapidly design clean, responsive, and custom user interfaces.</li>
    <li><strong>Vite:</strong> A lightning-fast build tool and development server providing instant hot module replacement (HMR) and optimized production builds.</li>
    <li><strong>Zustand:</strong> A lightweight, flexible state management library for React enabling efficient global state updates with minimal boilerplate.</li>
    <li><strong>Hostinger:</strong> A web hosting platform used for reliable deployment, fast production performance, and server resource management.</li>
    <li><strong>CodeRabbit:</strong> An AI-powered code review tool utilized for real-time pull request feedback, security detection, and maintaining code standards.</li>
  </ul>

  <hr>

  <h2>🔋 Core Features</h2>
  <ul>
    <li><strong>Immersive 3D Product Scenes:</strong> Highlight products in lifelike 3D environments featuring an advanced, realistic lighting system.</li>
    <li><strong>Scroll-Driven 3D Models:</strong> Animate and manipulate 3D models seamlessly based on the user's scroll position.</li>
    <li><strong>GSAP ScrollTrigger Effects:</strong> Power complex, multi-section scroll animations and timeline controls.</li>
    <li><strong>Pinned Sections:</strong> Lock vital content sections in view during scroll transitions for maximum engagement.</li>
    <li><strong>Dynamic Image Masking:</strong> Deliver visually striking image transitions utilizing scroll-triggered pins and masks.</li>
    <li><strong>Fluid Multi-Section Timelines:</strong> Craft cohesive, buttery-smooth animation flows across the entire page layout.</li>
    <li><strong>Fully Responsive Design:</strong> Ensure a flawless UI and adaptive performance across all devices and screen sizes.</li>
  </ul>
</div>
